# 验证范围

日期：2026-10-03。测试采用实际 Codex 内置图像生成/编辑能力；没有配置 API 凭据，没有安装额外引擎。工具未返回可核验的模型版本。

## 文件与行为

- 当前 skill-creator 的 `quick_validate.py` 对已安装版本返回 `Skill is valid!`，退出码 0。
- 安装文件与交付包内容一致；包保留默认自动发现，没有限制隐式调用的配置。当前宿主技能清单未热刷新，尚未完成新会话自动发现/装载验证。
- 独立场景干跑覆盖五个模式、缺原片、缺编辑工具、参考/内容/输出角色、二次展示证据、UI 和文字排除。均按技能执行所需分支；干跑不当作实际视觉测试。

## 实际图像测试

1. 一组公开展示的登山原片与干刷成片，在用户授权范围内私下做同图编辑；独立复核接受修正版达到“整体感觉相似”。保留帽子、长发、外套、背包、张臂姿势，但脸部及衣物细节绘画化，出现原裁切外的手部补画，景物仍更密。原片、目标及衍生图不再分发。
2. 公开 examples 使用本项目新生成的虚构旅行照片，同一原图分别实际编辑为五种模式。独立视觉检查确认五个方向区别、衣服/发型/姿势的大体保留、未见平台 UI 或文字。这是五模式合成输入试跑，不是五款公开原帖逐一同图验收。
3. 首轮发现干刷画面占比过大；蓝米/橄榄偏通用立体剪贴簿；橄榄新增压叶和花草细节；雪山橙线偏粗；深蓝增加胶带、小框和灯光。尺寸和“不新增”提示不能当作绝对保证。
4. 对干刷、蓝米、橄榄进行一轮定向编辑；采用更小的干刷构图，蓝米增加平面印刷和裸露纸面，橄榄去除压叶和堆叠小相框，减轻立体阴影。README 示例使用这三张修正版，另两款使用首轮输出。记录保留首轮不足，避免把修正当作约束已绝对保证。

五种来源中，教程二次展示的原帖仍未独立核验。单一合成输入没有验证跨照片稳定性、真实用户身份保真、全部 Kapi 效果、实时相机或视频。上述内容均不在首版完成声明中。
