## 展示加载检查

修复前 README 嵌入六张 1122×1402 PNG，合计 **18,880,022 字节**。实际 GitHub DOM 的图片地址是 `github.com/.../raw/main/examples/*.png`，重定向到 `raw.githubusercontent.com`；自然宽度 1122，表格显示宽度约 252。一次原图 GET 为 HTTP 200、3,215,728 字节、2.093158 秒。PNG 本身已有无损压缩；这里的问题是展示直接传输高清母版，缺少小尺寸预览。

修复后六个嵌图均使用 **560 像素宽 WebP，quality=86、method=6**；常规卡片 560×700，上下图 560×1400。共 **805,018 字节**，相对旧嵌图减少 **95.74%**。每张预览链接到保留的无损 PNG，高清不在 README 自动加载。压缩预览的体积：

独立查看接受压缩后的展示质量；完整母版可供细看。报告包含相对于同尺寸缩放母版的 PSNR，作为编码误差记录，不能替代视觉判断。体积变化不等于所有网络环境都能获得相同耗时；单次 GET 不是完整页面性能基准。
