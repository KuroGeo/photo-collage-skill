# Photo Collage · 照片撕纸拼贴

把用户授权的照片编排为静态拼贴。复古调色是颜色处理，裁剪、蒙版、叠层和纸纹是传统合成；补画背景或重绘纹理才涉及生成能力。不要根据效果外观断言 Kapi 的功能全部由 AI 实现。本技能不是 Kapi 接口封装。

## 输入与能力

- 区分**内容照片**和**风格参考**。内容照片必须由用户提供或明确授权；参考只用于分析视觉语言，不授权复制其中的人物照片。默认保留内容照片的人物身份特征、发型、服装、姿势和重要物件，不推断或识别参考人物身份。
- 原片缺失时，说明缺少哪些照片，并可先给出布局和编辑提示词；不要用参考中的人物代替用户，不调用工具生成“用户成片”，不宣称实测通过。演示输入只能用用户授权、自有或许可允许的素材，并明确标为演示。
- 默认使用 Codex 内置图像生成/编辑能力，无需用户配置 API key。若环境提供 `imagegen` 技能，先读取其内置工具流程；按当前图像工具的实际说明调用，不自行改用 CLI 或外部收费 API。当前工具名可能是 `image_gen.imagegen`，可用名称和参数以当次工具清单为准。查看本地图片后，按工具支持的本地路径或会话图片机制传入，不同时使用两种机制。
- 若没有支持输入照片的图像编辑工具，明确阻塞是“缺少能接受原片的图像编辑能力”；只交付可执行前的方案与提示词，不编造命令、MCP、API 或可用权限。纯文本生图不能代替保留本人照片的编辑。
- 本技能文本可开源；所调用的 AI 服务可能闭源、联网或收费。若用户要求纯开源或离线，先核实工具、模型、素材许可和运行方式是否满足要求；未满足时不要把服务调用称为纯开源离线方案。

## 工作流程

1. 查看授权原片和可选参考。记录主体、可裁剪区、需要保留的细节及输出比例；未指定时卡片使用竖版 4:5。用户指定风格或需要挑选时，读取 [五种风格配方](references/styles.md)。明信片或上下原图对照请求，读取 [输出模式与可选文字](references/postcard-output.md)：`output_mode=postcard_only`（默认）或 `stacked_original`，以及可选 `location`、`date`、`time`。未给文字留空，不推测地点时间、不自动公布 EXIF 信息。缺少参考时可采用下面的蓝米色配方。
2. 分析布局、撕纸轮廓与纤维、纸张颗粒、蓝与米色的比例、照片大小及前后关系。对社交平台截图，剔除状态栏、搜索栏、播放按钮、头像、点赞评论数字、字幕、账号和平台按钮；不把它们写入效果提示词。
3. 组装编辑提示词：**输入角色 → 主体保留项 → 布局 → 纸纹与调色 → 用户指定文字 → 排除项**。使用授权原片作内容输入，参考只作风格输入；不要直接编辑含陌生人物的截图来替代原片。未指定文字时不添加文案；指定小字时使用用户文本。
4. 使用当前实际可用且用户授权的图像编辑能力。默认只做拼贴、裁剪和整体调色；补画环境或其他内容应符合用户要求，不自行改变人物。保留现有透明背景，除非用户要求改变；普通纸质成片使用不透明背景。
5. 查看生成卡片，检查主体特征、服装、重要物件、裁切、纸层关系、参考 UI 是否残留。生成式编辑可能改变细节；不要保证生成卡片像素级保真，发现偏差时具体指出并针对修正。上下对照模式将授权原片原样置于上方、卡片置于下方，用已验证的确定性合成；可选文字确定性排到下卡片，检查无损母版上方像素与原片一致。无法查看工具结果时说明未做视觉检查。
6. 按所选模式返回单卡片或上下拼接单图。保留无损母版；网页/showcase 使用适当压缩预览并给出高清链接，不在 README 重复嵌多张大 PNG。压缩与拼接不重新生图、不覆盖原片。只有实际产物可取得才能报告生成或合成成功；方案、结构校验或干跑不能当作成片验证。

## Showcase 对照验收

用户要求参考公开展示时，记录实际看到的来源、风格与证据级别。展示的原图可在用户明确授权的范围内作为私下测试输入；成片不能默认为可再分发。分清原片、目标和本次输出；没有原片的参考只能做风格观察，教程内二次展示不能冒充已核验原帖。点赞数只是查看时的页面值，不能当作全平台榜单。

用同一原片编辑，按主体保留、画面占比与留白、轮廓、纸纹、颜色、照片/绘画程度检查整体感觉，剔除 UI。逐项说明相似处和差距，修正偏差后再验收。不要把五个已写配方说成五个都已生图通过。跨新照片的一致性需另测。

## 蓝米色撕纸配方

米色旧纸作为大面积底色；钴蓝天空色块与深色树枝形成对比。将授权人物照片排成错位的大小层次，辅以用户提供或允许生成的城市轮廓；不强制两个人或特定姿势。照片与纸片边缘不规则，露出浅色纸纤维，加入轻微贴纸投影、印刷颗粒和局部刷痕；保留呼吸空间，避免每块照片都用相同形状。

可直接改写的编辑提示词：

> 以提供的授权原片为内容，参考图仅提供配色、布局和纸张质感。保持原片人物的五官、发型、服装、姿势和重要物件。制作竖版 4:5 复古撕纸照片拼贴：米色旧纸底，钴蓝天空色块、深色树枝与城市细节穿插，照片错位叠放，粗糙不规则撕边、浅色纸纤维、细颗粒和轻微纸层投影。使用原片可用的环境细节；新增环境遵循用户要求。无用户指定文字则不加文案。去除参考的全部社交平台 UI，不复制参考人物、账号、点赞评论数字或平台按钮。

不安装 Kapi、不逆向或假设其 API、不复制付费模板、不配置密钥、不擅自将照片上传到额外第三方。首版只处理静态照片拼贴，不扩展实时相机或视频。
